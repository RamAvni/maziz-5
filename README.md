This project is an attempt to build an alternative public-transport app.

I try to use as little dependencies as possible.
Existing dependencies (if i didn't miss any, or did remember to update this file):
<ul>
    <li>Hardware</li>
    <li>The OS</li>
    <li>The Browser (html, css, js, wasm) runtime (and PWA support)</li>
    <li>The Typescript Compiler</li>
    <li>npm and pnpm</li>
    <li>SQLite and SQLite-WASM npm package (data storage)</li>
    <li>Leaflet (lib for Open Street Map in the website)</li>
    <li>geofabrik (for Points of Interest from Open Street Map)</li>
    <li>Hasadna's OPEN-BUS (api for GTFS and SIRI data)</li>
</ul>
