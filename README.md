This project is an attempt to build an alternative public-transport app.

I try to use as little dependencies as possible.
Existing dependencies (if i didn't miss any, or did remember to update this file):
    * Hardware
    * The OS
    * The Browser (html, css, js, wasm) runtime (and PWA support)
    * The Typescript Compiler
    * npm and pnpm
    * SQLite and SQLite-WASM npm package (data storage)
    * Leaflet (lib for Open Street Map in the website)
    * geofabrik (for Points of Interest from Open Street Map)
    * Hasadna's OPEN-BUS (api for GTFS and SIRI data)
